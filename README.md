# CS601 Personal Portfolio

## Project Description

This project is a personal developer portfolio created using React, TypeScript, HTML, and CSS as part of my CS601 Frontend Web Development final project.

The website showcases my professional background, education, technical skills, personal projects, and my journey into software development.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- TypeScript
- React
- Git and GitHub

## Website Pages

1. Home
2. About Me
3. My Journey
4. Skills
5. Projects
6. Learning Lab
7. Contact

## How to Run

1. Clone this repository
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000` in your browser
